# Used Car Price Predictor

- Developed an end-to-end machine learning pipeline to predict used-car selling prices using the CarDekho vehicle dataset.
- Performed data preprocessing, categorical encoding, feature transformations, and model selection using cross-validation and hyperparameter tuning with GridSearchCV and RandomizedSearchCV.
- The final model achieved a Mean Absolute Error (MAE) of ~₹1.16 lakh on the held-out test set, with feature-importance analysis used to identify the key factors influencing vehicle prices.
- There is 63% improvement on the Mean Absolute Error (MAE) over the baseline (dummy regressor) that predicts the mean of the prices in the training data.
